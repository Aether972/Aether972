## About

everything we bolted around them.

<!-- ==================== ATTACK SURFACE ==================== -->

## Attack Surface I Work On

| Layer | Focus |
|---|---|
| **Model** | Direct & cross-modal prompt injection · jailbreak transferability · refusal boundary mapping · training data extraction |
| **Application** | System prompt leakage · improper output handling · sensitive information disclosure · guardrail bypass |
| **Retrieval** | RAG poisoning · vector & embedding weaknesses · context injection via ingested documents |
| **Agentic** | Excessive agency · tool misuse · goal hijacking · memory persistence attacks · multi-agent cascade failures |
| **Supply chain** | Unsafe model serialization · compromised model weights · malicious dependencies in inference stacks |

> The 2026 OWASP guidance puts it plainly: stop trying to build a model that cannot be fooled,
> and harden the architecture around it so that when it is fooled, the blast radius is contained.
